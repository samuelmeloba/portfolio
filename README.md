### Costumer Behavior Analysis - Shopping Mall

Objective:
Explore patterns of customers of different malls in Turkey based on gender, age, and quantity of products purchased, using public data.

Tools Used:
R, ggplot2, dplyr, R Markdown

Summary:
 - Conducted exploratory data analysis on mall transaction data as part of a graduate-level course in data science.
 - Cleaned and prepared data by identifying duplicates, outliers, and missing values.
 - Applied descriptive statistics, visualized customer patterns, and performed hypothesis testing using R Markdown.
 - Found that most customers were women aged 18–64, predominantly paying in cash and purchasing 1–2 items priced between $2,300 and $17,000.
 - Analysis revealed stable sales trends over time, with higher purchase volumes among women.
 - Delivered insights in a structured academic report format.
